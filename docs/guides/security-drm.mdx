# 扫描、水印与 DRM / Scanning, watermarking and DRM

上传后并行执行 ClamAV、VirusTotal、YARA 与启发式引擎。恶意文件进入隔离区，可疑文件进入人工复核；引擎错误不会被误判为安全。所有结果产生扫描事件。

The raw-image watermark embeds an HMAC-authenticated payload into DCT coefficient relationships with repetition and majority decoding. Visible SVG overlays escape XML input. DRM checks action, user, MIME, CIDR, device, view count and expiry before content access. Screenshot prevention is a client policy signal, not an operating-system guarantee; deployments must combine it with visible/invisible forensics.
