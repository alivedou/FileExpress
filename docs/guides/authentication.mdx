# 认证与授权

## 访问通道

公开分享和六位提取码是兼容的匿名传输通道，企业管理 API 是另一条受控通道。不要把提取码当成用户身份，也不要用六位码调用管理接口。

管理端支持两类凭据：

1. `Authorization: Bearer <ADMIN_API_TOKEN>`，用于受控管理员。
2. `X-API-Key: fe_*`，用于带租户、权限、时间窗和速率限制的服务账号。

生产环境未配置管理员令牌时，该通道不会自动放行。开发默认令牌只能用于本机开发，不能复制到部署环境。

## API Key 生命周期

创建密钥时设置名称、租户、权限、每分钟请求数和到期时间。完整秘密仅出现在创建响应中，列表接口只返回前缀、Scope 和撤销状态，不返回哈希。

```json
{
  "name": "upload-automation",
  "scope": {
    "tenantId": "team-a",
    "projectId": "project-b",
    "bucket": "uploads",
    "permissions": ["storage.write"],
    "requestsPerMinute": 60,
    "notBefore": "2026-11-22T00:00:00.000Z",
    "expiresAt": "2027-01-01T00:00:00.000Z"
  }
}
```

撤销后认证立即失败，速率窗口被清除。密钥应定期轮换，轮换期间先创建新密钥、迁移调用方、验证流量，再撤销旧密钥。

## 权限映射

- 存储读取：`storage.read`
- 上传和安全扫描：`storage.write`
- 存储注册及系统配置：`settings.manage`
- Webhook 管理：`webhook.manage`
- 团队、角色和 API Key：`team.manage`
- 审计读取与导出：`audit.read`
- 账单读取：`billing.view`

自定义角色可继承内置角色或其他自定义角色，服务会检查循环和最大深度。权限检查同时约束租户、项目、桶和时间范围。

## 租户一致性

API Key 请求必须携带 `X-Tenant-Id`。如果 query、body 或嵌套 Scope 也包含租户，它们必须与请求头一致。撤销密钥时还会检查目标密钥所属租户。

项目与桶通过 `X-Project-Id` 和 `X-Storage-Bucket` 限定。未携带这些请求头时，带对应限制的密钥不能访问更宽资源。

## 审计与管理边界

管理写操作由服务端记录方法、路径、状态、来源 IP、User-Agent 和结果，不记录请求秘密或文件内容。审计记录使用追加式存储和签名链。

管理员令牌不是完整的用户登录方案。面向企业的交互式登录应接入 OIDC/SAML 身份提供方、短期会话和 MFA；当前仓库中的 API Key 与管理员通道不能替代这些能力。

## 密钥安全

禁止在源码、镜像、Helm values 或日志中保存真实秘密。使用外部 Secret 注入，限制读取权限，启用传输加密，并在泄露后同时轮换管理员令牌、API Key、Webhook 签名密钥和受影响的存储凭据。
