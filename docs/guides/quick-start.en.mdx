# Quick start

## Requirements

- Node.js 20 or later.
- npm 10 or later.
- At least 512 MiB of available memory for local development.
- Independent encryption, webhook signing and administrator secrets in production.

## Install and run

```bash
npm install
cp .env.example .env
npm run dev
```

The development server listens on `0.0.0.0:3000` by default. Never commit `.env`; use Kubernetes Secrets, GitHub Secrets or a cloud secret manager in production.

A minimal production configuration is:

```dotenv
NODE_ENV=production
DATA_DIR=/data
STORAGE_BACKEND=local
STORAGE_ENCRYPTION_KEY=<random-value-at-least-32-characters>
WEBHOOK_SIGNING_SECRET=<independent-random-value>
ADMIN_API_TOKEN=<high-entropy-administrator-token>
```

The service refuses to start without required production secrets. When the legacy encryption key is absent in development, a process-random key is used and legacy small files cannot be decrypted after a restart. Set a stable development key as well.

## First upload

The compatibility endpoint remains available for private files below 100 MiB:

```bash
curl -X POST http://localhost:3000/api/upload/private \
  -F 'files=@./README.md' \
  -F 'duration=24' \
  -F 'maxDownloads=5'
```

The response contains a six-digit `pickupCode`. Resolve it through `/api/extract`, then download from `/api/download/{code}`. Large files must use Tus or custom chunks. Their completion response returns a pickup code allocated by the persistent catalog.

## Administration

Open `/admin` and enter the administrator token. Storage, scanning, DRM, webhook, team, role, audit and monitoring pages call `/api/admin/*`. API key clients also send `X-Tenant-Id` and may narrow scope with `X-Project-Id` and `X-Storage-Bucket`.

## Verify startup

```bash
curl --fail http://localhost:3000/health/live
curl --fail http://localhost:3000/health/ready
curl --fail http://localhost:3000/metrics
npm run typecheck
npm run lint
npm run test:coverage
npm run build
```

Readiness returns 200 only when every enabled backend is healthy. It returns 503 when a dependency is unavailable so the orchestrator stops routing traffic.
